Practical 8

MySQL Schema Design, ER Model, PDO Connectivity and Prepared Statements

Problem Definition Design the database for StudentHub with students, events and registrations. Create PHP database connection using MySQL statements.
Key Questions / Analysis / Interpretation
  1. Is the schema normalized properly?
  2. Are primary keys and foreign keys correctly defined?
  3. Is the database connection handled securely?
Key Skills to be Addressed ER modeling, MySQL, phpMyAdmin, database error handling
Applications Secure database-backed web applications
Learning Outcome Students will design and connect a normalized database securely using PHP.
CO Mapping CO1, CO5
Dataset / Test Data SQL seed data for students, events and registrations
Tools / Technology to be Used MySQL, phpMyAdmin, PHP, XAMPP
Total Hours Implementation: 4 hours | Total engagement: 6 hours
Post Laboratory Work Submit SQL dump, db.php file and connection test screenshot.
Evaluation Strategy Including Viva Database, database connections and DB viva
Advanced / Intermediate Extension Intermediate: Use PHP PDO and Prepared Statement.
Advanced: Add stored procedure concept.
